Команды Git
Команда Описание
git init Создает новый пустой Git-репозиторий в текущей папке
git clone url Копирует удаленный репозиторий из интернета (GitHub) на ваш компьютер
git add file Добавляет указанный файл в список отслеживаемых (подготовка к коммиту)
git add . Добавляет ВСЕ измененные файлы в список отслеживаемых
git commit -m "comment" Сохраняет изменения с комментарием (сообщением)
git commit -a -m "comment" Добавляет все отслеживаемые файлы И делает коммит за одну команду
git push url Отправляет ваши коммиты с компьютера на удаленный репозиторий (GitHub)
git status Показывает состояние репозитория: какие файлы изменены, добавлены, ожидают коммита
git log Показывает историю всех коммитов (кто, когда, что изменил)
git branch branch_name Создает новую ветку с указанным именем
git checkout branch_name Переключается на указанную ветку
git checkout -b branch_name Создает новую ветку И сразу переключается на нее
git remote Показывает список удаленных репозиториев, связанных с вашим проектом
